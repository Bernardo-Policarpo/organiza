# Banco de Dados

Este diretório contém todos os artefatos relacionados ao banco de dados do projeto Organiza$.

## Estrutura
- `migrations/`: Arquivos de migração do banco de dados (Flyway/SQL).
- `scripts/`: Scripts SQL para criação inicial, carga de dados de teste ou manutenção.
- `docs/`: Documentação do modelo de dados, diagramas ER e dicionário de dados.

## Tecnologias
- **MySQL 8.0+**
- **Flyway** para controle de versão.
